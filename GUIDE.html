Freedom Email Archiver — User Guide

Keep your emails on your own computer, browse them offline and move your archive whenever you need to. No account, server or internet connection is required.

1. One portable archive

The application and your emails stay together in freedom_email_archiver/ (or any folder name you choose). Open its index.html to use the archive. Keep the assets/ and archived_emails/ folders beside it.

freedom_email_archiver/
  index.html
  GUIDE.html
  assets/
  archived_emails/
    catalog/
    example/
    personal/
      catalog/
      2025/2025-01/email-....html
      2025/2025-01/attachments/
    work/

All accounts, saved email pages, attachments, optional EML files and search indexes are stored in archived_emails/. The example/ account contains four fictional sample messages. The app always uses this folder; it does not create another copy of itself or let you choose a separate data folder.

2. Browse your emails

  • Double-click index.html and choose Browse archive.
  • Search by subject, address or message text. Use the filters to narrow your results.
  • Click a message to open it. Use Back to archive or your browser's Back button to return.
  • Switch between Light and Dark mode in the top bar. Older saved messages may keep their original appearance.

No folder permission is needed to read an indexed archive. External images may contact the sender's servers. Turn off Load external images automatically if you prefer not to load them.

3. Import emails from MBOX

  1. Open Import in desktop Chrome or Edge.
  2. Click Enable archive access and select the application folder, for example freedom_email_archiver/, containing index.html. Do not select archived_emails/ or the MBOX file in this dialog.
  3. Select one or more MBOX files using the file selector.
  4. Choose an account or create one with + New account…. Select any optional EML copies you want to keep.
  5. Click Start import and wait until it finishes. Then return to Browse archive.

You only need to grant folder access once, unless the browser expires or revokes the permission. If that happens, use Enable archive access again. Import, Check existing and Rebuild index do not open a folder picker.

Import adds new messages, skips duplicates and merges Gmail labels. Messages already in your archive are not deleted just because they are missing from a newer MBOX export. The original MBOX stays unchanged. Import uses the saved index and does not scan or rewrite unrelated saved emails.

While importing: keep the tab open. Never run two write operations on the same archive at once, even on different computers using a synced folder.

4. Check or rebuild the archive

Check existing

Use this to find missing or unreadable emails, missing attachments or EML files, and problems with the index. It checks files but does not change anything.

Rebuild index

Use this after adding, removing or merging account folders, or if the index is damaged. The app rebuilds the list of messages and search indexes from the saved HTML files. It does not change the emails, attachments or EML files. If the rebuild fails or is stopped before publication, the previous index is kept.

Both actions need archive access and show a progress bar. You do not need an MBOX file or a separate check before rebuilding.

5. Move, merge or back up your archive

When you open the archive with saved write access, the app automatically checks account folders. If you remove a whole account, it removes that account from the main catalog without rebuilding other accounts. If you copy in a complete account with a valid index, the app can add it without reading the saved emails. Without write access, unavailable indexes are skipped; the catalog stays unchanged. Accounts with missing or ambiguous indexes need Rebuild index.

  • To back up or move your archive, copy the entire application folder, including index.html, assets/ and archived_emails/.
  • To create a separate archive, copy the whole folder to another location.
  • To merge archives, back them up first. Copy the account folders into archived_emails/ and keep their year/month, attachment and EML folders intact. Resolve file conflicts carefully, then click Rebuild index.
  • To recover saved emails without an index, back them up first, copy their account folders into freedom_email_archiver/archived_emails/ and click Rebuild index.

If you use pCloud or another sync service, make sure all files are available offline before importing, checking or rebuilding. Allow syncing to finish before writing to the archive on another computer.

6. Security and limitations

  • Browser: use desktop Chrome or Edge for import, checking and rebuilding. Other browsers may open saved emails, but have not been fully tested.
  • Message size: the limit is 64 MiB per message. Oversized or damaged messages are reported as errors. Source files are not changed.
  • Email safety: imported email scripts are removed or blocked. Some original formatting may change. The archive is not encrypted, so protect private files and backups.
  • Original EML: optional copies can be kept for signed or encrypted messages, Gmail Starred messages and Gmail Important messages. Keep the original MBOX if you need to verify signatures or preserve the original mail source.
  • Windows Defender: the app cannot turn off security warnings. Review Windows Security → Protection history if a warning appears.
