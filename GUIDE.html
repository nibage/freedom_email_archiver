Freedom Email Archiver — Offline Guide

The archive is one portable folder. Its index.html and assets/ sit beside archived_emails/. All accounts, saved HTML messages, attachments and indexes belong inside archived_emails/. No separate data folder is selectable and the application never copies itself.

Read without permission

Double-click the application index.html. Already indexed mail loads through relative script files from archived_emails/, so there is no server and no permission dialog for ordinary browsing. Click a message to open its standalone HTML page in the same tab, even after authorizing archive access. Use Back to archive or browser Back to return. Current message pages use the light/dark preference and retain safe message formatting; older pages may keep their original appearance. External pictures may contact senders; switch off Load external images automatically when privacy matters.

Import a new MBOX

  1. Click Enable archive access once. In the Chrome/Edge directory picker select the folder containing the opened index.html, for example email_archiver_root/. Do not select your MBOX or archived_emails/ here.
  2. Choose your MBOX using its own file selector and choose the account (or + New account…).
  3. Click Start import. With access granted, it begins directly; it never opens another folder picker. If access has expired, it displays a clear explanation rather than opening a chooser.
  4. The app reads the selected MBOX and saved catalog for deduplication, then saves new messages to the chosen account inside archived_emails/. It does not scan or update the rest of your saved HTML library. The original MBOX remains untouched.

Browsers do not let ordinary file:// pages silently grant themselves write access. Enable archive access is the only control that may open the browser's directory picker. Start import and Check existing reuse the previously authorized handle and never ask for a second file or folder selection.

Check existing: read-only verification

After enabling archive access, use Check existing to inspect only archived_emails/. It validates saved HTML, catalog/search shards and local attachment/EML references. It reports unindexed files, stale catalog references, invalid HTML and missing files. It never changes any file or requests a write lock. Both Check existing and Rebuild index display progress based on the saved HTML file count.

Rebuild index: recover saved mail without MBOX

Copy, remove or merge account folders inside archived_emails/, preserving year/month and attachment paths. Then click Rebuild index (formerly Reimport only existing). No MBOX is needed and no prior check is required. It rebuilds only metadata and text-search indexes from the HTML physically present under all accounts. It does not rewrite message HTML, update appearance or modify attachments/EML. An incomplete or invalid rebuild does not replace the published catalog.

If the old __email_archiver/ folder was deleted, back up the remaining files, copy only the surviving account folders into archived_emails/, then use Rebuild index. If your catalog is damaged, use this action explicitly before importing another MBOX.

Backup and relocation

Back up or move the entire email_archiver_root/ folder, including application files, catalogs and every account. You can create a second independent archive by manually copying this root to another location. Only one writer may modify an archive at a time, including over pCloud or other synced drives. Make all synced files available offline before repair/import.

Security and limitations

No server, telemetry, account or cloud API is required. Scripts in saved email HTML are treated as untrusted. The optional original EML retention settings preserve selected signed/encrypted or Gmail-labelled messages; keep the source MBOX for exact MIME provenance. The 64 MiB per-message limit remains in effect. Chrome/Edge support filesystem writes; other browsers may read the indexed HTML but external browser behavior is not independently verified.

Windows Defender notifications cannot be disabled by the app. Inspect the details in Windows Security → Protection history before changing any protection settings.
