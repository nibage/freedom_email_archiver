Freedom Email Archiver — Offline Guide

The program is separate from your email data. Open the application’s index.html, select one data root, and browse or import every account inside that root. The program never copies itself into a selected folder.

Application and data folders

Keep the program’s index.html, GUIDE.html and assets/ in an application folder of your choice. In a second folder, keep your mail accounts grouped by year/month. New imports create catalog/archive.js, account folders, attachments and optional original EML files only in the selected data folder. The program does not create a second index.html or a launcher there.

You can manually copy the application folder to create a separate installation. Each instance remembers its own selected data-root handle when the browser permits. One running instance has just one active root: choosing another immediately replaces Browse messages, accounts and search data.

Choose, browse and search

  1. Use desktop Chrome or Edge and open the application index.html directly from the filesystem.
  2. Click Choose data folder in Browse or Import. The selection is read-only and does not scan every message or create files.
  3. Browse the selected root’s indexed messages. The app loads catalogs through the browser’s File System Access permission, not from its own folder or a server.
  4. Click a message to read it in an isolated viewer inside the same tab. Back to archive returns to your list. Attachments and CID images are accessed locally.

The message iframe has no script or same-origin permission. HTML mail retains its original safe formatting. Light and dark modes also style the reader shell. External pictures may disclose an IP address or tracking identifier: uncheck Load external images automatically to block them until you request them.

Import an MBOX

  1. Select the data folder (the same root is active for Browse).
  2. Choose one or more MBOX files, including extensionless Thunderbird exports.
  3. Under Email account folder inside the archive, choose a saved account or + New account….
  4. Click Start import. Existing HTML pages and catalogs are checked first; then new messages are added to the selected account. Duplicate messages are skipped and Gmail labels are merged.

Leave the page open during writes and use only one writer for an archive. The source MBOX is not modified. The maximum message size is 64 MiB. Stop and retry are supported. Back up the entire data root before a large import or repair.

Check existing and refresh saved HTML

Check existing performs a deep, read-only catalog and saved-HTML scan. Reimport only existing can rebuild missing indexes and update recognized old message viewer shells without the MBOX, keeping original bodies and attachments. Unrecognized altered message pages are skipped. The update acquires a writer lock only when necessary.

Backup and relocation

Back up the complete data folder and the separate application folder. New data-only roots use catalog/ and account folders; existing archives may still contain older assets/catalog/ or __email_archiver/ structures, which remain supported without being deleted or moved. After restoring files elsewhere, open the application and select the restored data root again. Browser permission is not a substitute for a backup.

Saved email-*.html pages can still be opened individually without the application, although older embedded Back links may not reach the separately stored program. The app’s integrated viewer handles navigation.

Safety and limitations

No server, account, telemetry or cloud API is needed. The app uses browser filesystem access and will not construct unverifiable file:// URLs from directory names. Chrome/Edge are targeted for selecting data folders; Firefox/Safari external-root browsing is not verified. Email contents are not encrypted. Keep the MBOX for original MIME data and cryptographic signatures; preserved optional EML copies are not automatically signature-verified.

If Windows Defender shows a warning, inspect its details in Windows Security → Protection history. Controlled folder access may block writes; do not disable protection or exclude entire mail archives as a workaround.
